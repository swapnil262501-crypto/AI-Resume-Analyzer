# AI Resume Analyzer

[![Python](https://img.shields.io/badge/Python-3.11-blue?logo=python&logoColor=white)](https://www.python.org/) [![Flask](https://img.shields.io/badge/Flask-2.3-green?logo=flask&logoColor=white)](https://flask.palletsprojects.com/) [![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**AI Resume Analyzer** is a professional, interactive, and modern Flask-based web application that allows users to **upload PDF resumes**, extract relevant information such as **Email, Phone, Skills, Education**, and view a **dynamic summary**.  

It is designed to be **MNC-level ready**, visually appealing, and suitable for professional use.

---

## 🌟 Features

- Upload **PDF resumes** and extract information instantly.  
- Extract and display:
  - **Email**
  - **Phone number**
  - **Skills** (full names, all types, no short forms)  
  - **Education & Qualifications**  
- Interactive **Summary button** for concise resume overview.  
- Professional and dynamic UI with live background animation.  
- Watermark for branding with GitHub username: `swapnil262501-crypto`.  
- Fully modular and readable code using **Flask + PyPDF2 + Python regex**.

## ⚙️ Installation & Usage

1. **Clone the repository:**

'''bash
git clone https://github.com/SwapnilAwasthi/AI-Resume-Analyzer.git
cd AI-Resume-Analyzer'''

Create a virtual environment:

python -m venv venv


Activate the virtual environment:

# Windows
venv\Scripts\activate

# Mac/Linux
source venv/bin/activate


Install dependencies:

pip install -r requirements.txt


Run the Flask app:

python app.py


Open your browser and go to:

http://127.0.0.1:5000

📝 Usage Instructions

Click the Upload PDF button and select your resume.

Click Submit to analyze the resume.

View the professional results page:

Email

Phone number

Skills

Education

Click “Show Summary” button to see a concise summary of the resume.

Fully interactive and modern UI designed for professional presentation.

📦 Dependencies

Python 3.x

Flask – Web framework

PyPDF2 – PDF parsing

re – Python built-in regex for parsing

All dependencies are included in requirements.txt.
